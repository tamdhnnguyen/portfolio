🌾 Project 1 — AI-Powered Wheat Disease & Pest Classification (Capstone Project)

This capstone project developed an end-to-end deep learning system to identify wheat diseases and pest infestations from images and provide treatment recommendations. A two-stage classification pipeline first distinguishes healthy from unhealthy wheat, then performs fine-grained disease and pest classification.

Highlights:

  • ✔️ Built a two-stage CNN classification pipeline for wheat disease and pest identification
  • ✔️ Trained on 13,104 high-resolution images across 15 classes
  • ✔️ Applied class weighting, data augmentation, transfer learning, and fine-tuning
  • ✔️ Achieved 92.17% accuracy and 91.73% F1 score with the final two-stage system
  • ✔️ Deployed a Streamlit web app for image-based predictions and treatment recommendations

🛡️ Project 3 — Fraud Detection in Automobile Insurance Claims

This project utilizes an insurance claims dataset from Kaggle to detect and forecast possible fraudulent claims. The analysis helps insurance companies with risk segmentation, fraud detection, and equitable pricing strategies.

Highlights:

  • ✔️ Cleaned and preprocessed insurance claim data
  • ✔️ Used data visualization (Matplotlib, Seaborn) to detect patterns associated with car accidents and fraud
  • ✔️ Applied machine learning (Scikit-learn) models to develop a risk rating model
  • ✔️ Insights help in detecting high-risk customers and preventing fraud
